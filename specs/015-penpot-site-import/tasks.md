# Tasks: Import a website from a Penpot file

**Input**: Design documents from `/specs/015-penpot-site-import/`

**Prerequisites**: plan.md, spec.md (with Clarifications 2026-10-06), research.md (P1–P16), data-model.md, contracts/site-import-api.md, contracts/penpot-conversion.md, quickstart.md

**Tests**: Included. The constitution (Principle IV) makes automated tests
mandatory for data transformations (the converter), custom endpoints, access
rules and job logic; spec SC-007 asks for crafted hostile files.

**Organization**: by user story, in priority order. US1 (P1) import boards as
draft pages; US2 (P2) links between pages; US4 (P2) domain fonts; US3 (P3)
re-import. US4 comes before US3 because it is P2 and is useful on its own.
Paths are relative to the repo root. Branch: `015-penpot-site-import`.

**Reference material** (outside the repo): `../penpot/references/*.penpot`
(4 reference sites), `../penpot/references/generator/` (builder scripts,
`render.sh` for Penpot's own PNG rendering), local Penpot at
http://localhost:9001 (`docker compose -p penpot up -d` in `../penpot/`).

## Format: `[ID] [P?] [Story] Description`

- **[P]**: Can run in parallel (different files, no dependency on an unfinished task)
- **[Story]**: US1, US2, US3, US4 (spec.md)
